更新记录
================================================

当前版本：V1.25（2026-08-09）

以下按版本顺序累积记录各版本更新内容（由旧到新，最新版本在最末）：


【V1.03 · 2026-08-08】
基线版本：个人主页前台展示与后台管理基础模块（站点配置、作品管理、留言板等）。

【V1.04 · 2026-08-08】
新增云更新 / 备份恢复 / 真实改密码 / 多链接编辑；作品墙、留言板（带审核）；SEO 结构化数据；安全加固（Nginx 屏蔽规则、链接校验白名单）。

【V1.05 · 2026-08-08】
安装向导页（install/index.php）液态玻璃视觉改版：渐变背景 + 浮动光斑、玻璃卡片/输入框/按钮、四步指示器、亮暗主题切换；去除安装页所有数据库名实例；建立版本化部署包机制（累积式更新记录、版本号递增）。

【V1.06 · 2026-08-09】
云更新手动确认机制：管理端上传更新包仅暂存为「待更新」（pending），不再自动应用；后台云更新界面展示待更新压缩包信息（版本 / 日期 / 说明 / SHA256 / 文件名），用户手动点击「确认更新」后才执行下载→校验→备份→安全解压→写版本号→失败自动回滚，激活后标记已应用并清除 pending；pre_updates 表新增 status 状态列（自动平滑补列，兼容旧表）。

【V1.07 · 2026-08-09】
云更新发布页增强：独立发布后台上传更新压缩包后，自动读取包内「更新记录.txt」并提炼最新版本块，填充至「更新说明」内容框作为默认值，允许用户二次编辑/补充；提炼兼容根目录与带顶层目录两种布局；无更新记录文件时留空并提示手动填写。

【V1.08 · 2026-08-09】
修复后台云更新「确认更新」按钮缺失：补全确认弹窗（版本 / 日期 / 说明 / SHA256 / 文件名 + 确认 / 取消按钮，z-index 置顶、遮罩点击与 Esc 关闭）与对应 JS（openPendingModal / dismissPending / submitConfirm），页面加载后自动弹出；保留内联面板确认按钮作为无 JS 兜底；POST 处理块加顶层 try/catch 防止致命错误空白页。

【V1.09 · 2026-08-09】
修复云更新管理端首次上传后 update.json 404：regenerateUpdateJson() 原逻辑只在存在 is_current=1 的已发布版本时才生成 update.json，导致全新部署站点首次上传 pending 包后文件被删、后台拉取 404。现改为：无 current 但有 pending 时仍生成 update.json，version 取站点当前版本避免误判，pending 信息照常附带，确保后台「确认更新」按钮可正常出现。

【V1.10 · 2026-08-09】
修复新部署站点云更新两处兼容性问题：① getSiteVersion() 改为优先读取静态 version.json，避免 config 表旧版本值覆盖当前真实版本，解决后台「当前版本」显示错误；② fetchRemoteVersion() 放宽 JSON 校验，允许「无 current 但含 pending」的 update.json，解决只有待更新包时提示「JSON 格式不正确」；③ applyRemoteUpdate() 与后台 hasPending 改为 pending 包版本不低于当前版本即可确认更新，支持同版本覆盖重装。

【V1.11 · 2026-08-09】
修复云更新两处交互与接口问题：① 后台云更新「取消 / 暂不更新」按钮点击无反应：dismissPending() 现在会同时关闭弹窗、隐藏顶部提示条与内联面板，并通过 sessionStorage 记忆用户本次会话已忽略该 pending 版本，避免反复弹窗打扰；② 独立云更新管理页上传压缩包后无法自动提取「更新记录.txt」：upload.php 同时支持 $_GET['action'] 与 $_POST['action']，使前端 fetch('upload.php?action=peek') 请求能正确进入 peek 分支返回 JSON。

【V1.12 · 2026-08-09】
安全与体验优化：后台增加 CSRF、防暴力登录和安全 Cookie；普通源码 ZIP 上传后自动剔除数据库配置、数据和上传目录再发布；已登录后台使用签名令牌，兼容宝塔部署。

【V1.20 · 2026-08-09】
优化首次云更新提示：尚未上传版本包时，明确引导先在云更新管理暂存版本，不再将 update.json 的 404 误显示为拉取失败。
