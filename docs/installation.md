# 安装说明

> 适用版本：V1.24 及以后版本  
> 适合人群：第一次使用服务器、宝塔面板或网站后台的用户。  
> 网站装好之后，日常使用请继续阅读 [用户手册](user-guide.md)。

---

## 1. 先了解要做什么

可以把部署网站理解成“开一家店”：

- **服务器**是店铺所在的房子；
- **宝塔面板**是管理房子的工具；
- **域名**是店铺门牌号，例如 `www.example.com`；
- **数据库**是放置网站设置、管理员账号、留言等信息的保险柜；
- **源码包**是店铺的装修和功能。

本节会带你把源码上传到服务器、连接数据库、完成安装，最后通过域名访问网站。

## 2. 部署前必须准备的内容

请先逐项确认。缺少其中任何一项，都可能导致安装中断。

### 2.1 服务器和网络

- 一台已开通的 Linux 云服务器。常见的 CentOS、Ubuntu、Debian 都可以。
- 建议至少 1 核 CPU、1 GB 内存、20 GB 可用硬盘；访问量较大时请提高配置。
- 服务器已安装并能登录宝塔面板。
- 云服务器安全组和服务器防火墙已放行 **80 端口**（HTTP）和 **443 端口**（HTTPS）。
- 记下服务器的公网 IP 地址。

### 2.2 域名和解析

- 已购买一个域名，例如 `example.com`。没有域名时也可先用服务器 IP 测试，但正式上线建议使用域名和 HTTPS。
- 在域名服务商后台添加一条 **A 记录**，把域名指向服务器公网 IP。
- 等待解析生效。通常数分钟到数小时不等；解析未生效前，宝塔申请 HTTPS 证书会失败。

### 2.3 宝塔软件环境

在宝塔的“软件商店”中安装或确认以下软件：

- Nginx 或 Apache（二选一；新手推荐 Nginx）；
- MySQL（建议 MySQL 5.7+ 或兼容版本）；
- PHP **7.2 及以上**，推荐 PHP 8.1；
- PHP 扩展：`pdo_mysql`、`curl`、`zip`。建议同时启用 `mbstring`。

为什么要装这些？PHP 负责运行网站，MySQL 保存数据，`zip` 用来制作和安装云更新包，`curl` 用来检查更新。

### 2.4 本地准备

- 下载本项目的源码压缩包，例如 `site_source_V1.26.zip`。
- 准备一个强密码，稍后用作管理员密码。密码请同时包含大小写字母、数字和符号，且不要少于 10 位。
- 记录数据库信息：数据库名、数据库用户名、数据库密码、主机地址（通常是 `127.0.0.1`）和端口（通常是 `3306`）。

## 3. 用宝塔创建网站和数据库

### 第 1 步：登录宝塔

在浏览器打开你的宝塔面板地址并登录。进入后先确认主页中的 Nginx、MySQL、PHP 均显示“运行中”。

### 第 2 步：创建数据库

1. 打开左侧的“数据库”。
2. 点击“添加数据库”。
3. 填写数据库名、用户名和强密码。
4. 访问权限选择“本地服务器”即可。
5. 点击确认，并把数据库名、用户名、密码保存到安全的位置。

> 不要把数据库密码发到聊天、截图或公开文档中。

### 第 3 步：创建网站

1. 打开左侧的“网站”，点击“添加站点”。
2. 填写已经解析好的域名；如果同时使用 `www` 域名，可一并填写。
3. 根目录使用宝塔自动生成的目录即可，例如 `/www/wwwroot/example.com`。
4. PHP 版本选择 PHP 8.1（或已安装的 PHP 7.2+ 版本）。
5. 点击“提交”。

创建后，点击该网站的“设置”，确认运行目录就是网站根目录，不要指向压缩包内多出来的一层文件夹。

## 4. 上传并解压源码

1. 在宝塔“网站”列表中找到刚创建的网站，点击“根目录”。
2. 上传 `site_source_V1.26.zip`。
3. 上传完成后，选中压缩包并点击“解压”。
4. 确认根目录中能直接看到 `index.html`、`admin`、`includes`、`install`、`update-admin`、`data` 等内容。

常见错误：如果文件被解压成 `/www/wwwroot/example.com/site_source_V1.26/index.html`，网站根目录会找不到首页。此时请把 `site_source_V1.26` 文件夹里的内容移动到网站根目录，或把网站运行目录改到该文件夹内。

## 5. 设置权限和 PHP 扩展

### 第 1 步：确认 PHP 扩展

在“软件商店”找到正在使用的 PHP 版本，点击“设置 → 安装扩展”，确认已安装：

- `pdo_mysql`
- `curl`
- `zip`
- `mbstring`（建议）

安装或启用后重启 PHP。

### 第 2 步：调整上传大小

云更新需要上传 ZIP 压缩包。打开“PHP 设置 → 配置修改”，将下面两项设置为大于你的源码包，例如 `128M`：

- `upload_max_filesize`
- `post_max_size`

保存后重启 PHP。若源码包更大，请相应提高数值。

### 第 3 步：确认可写目录

安装过程需要写入数据库配置，日常运行需要写入数据、上传文件、备份和更新包。请确保 PHP 运行用户对以下目录有写入权限：

- `includes/`（仅安装时需要写入 `db.php`）；
- `data/`；
- `uploads/`；
- `update-admin/releases/`（首次上传更新包后会自动创建）。

在宝塔文件管理器中可使用“权限”功能，把网站目录所有者设为 Web 服务运行用户（宝塔常见为 `www`），目录通常使用 `755` 即可。不要为了省事把整个网站设置为 `777`。

## 6. 添加必要的安全规则

如果使用 Nginx，在“网站 → 设置 → 配置文件”的 `server { ... }` 中加入下面规则，然后点击保存并重载 Nginx：

```nginx
location ~ ^/(?:data|includes|install)/ { deny all; }
location ~ /\. { deny all; }
location ~* ^/uploads/.*\.(?:php[0-9s]?|phtml|phar|cgi|pl|py|sh)$ { deny all; }
```

这三条规则的作用是：不让访客直接下载数据库配置和数据文件，不让安装目录再次被打开，也不让上传目录执行脚本。

> 若你使用 Apache，请在 Apache 的站点配置中做相同的访问限制。部署完成后可阅读同目录的 `deployment-security.md` 获取更完整的安全检查说明。

## 7. 打开安装向导

1. 在浏览器访问：`https://你的域名/install/`。
2. 第一步“环境检测”全部通过后继续。若提示缺少扩展，回到宝塔安装相应 PHP 扩展。
3. 第二步填写数据库信息：
   - 主机：通常为 `127.0.0.1`；
   - 端口：通常为 `3306`；
   - 数据库名、用户名、密码：填写第 3 节创建的内容。
4. 点击“测试连接”。显示成功后继续。
5. 第三步设置网站标题、管理员账号和管理员密码。
6. 最后点击安装完成。

安装向导会自动建立数据表、写入管理员账号、生成数据库配置和安装锁文件。

## 8. 安装完成后的检查

请依次访问：

1. `https://你的域名/`：应能看到网站首页；
2. `https://你的域名/admin/login.php`：应能看到后台登录页；
3. 使用刚创建的账号密码登录后台；
4. 访问 `https://你的域名/data/`、`https://你的域名/includes/`、`https://你的域名/install/`：应显示 403 或 404，而不是文件内容。

安装完成后，建议删除服务器上 `install/` 目录，或至少确认第 6 节的 Nginx 规则已经阻止访问它。不要删除 `install/install.lock`，它用于防止重复安装。

## 9. 开启 HTTPS

1. 宝塔“网站 → 设置 → SSL”。
2. 选择 Let's Encrypt，申请域名证书。
3. 勾选“强制 HTTPS”。
4. 保存后用 `https://你的域名/` 重新访问。

如果证书申请失败，优先检查域名是否已解析到本服务器，以及 80/443 端口是否放行。

## 10. 常见安装问题

| 现象 | 常见原因 | 处理方法 |
| --- | --- | --- |
| 打开域名显示默认宝塔页面 | 网站根目录或域名绑定错误 | 检查站点域名和运行目录，确认首页文件在根目录。 |
| 安装向导提示数据库连接失败 | 数据库名、账号、密码或端口错误 | 回到宝塔数据库列表核对信息，先使用“测试连接”。 |
| 提示无法写入 `includes/db.php` | 目录没有写入权限 | 将网站目录所有者调整为 Web 服务用户，确认 `includes/` 可写。 |
| 云更新提示缺少 ZipArchive | PHP 未启用 `zip` 扩展 | 在对应 PHP 版本中安装 `zip` 后重启 PHP。 |
| 上传 ZIP 提示文件过大 | PHP 上传限制太小 | 提高 `upload_max_filesize` 和 `post_max_size`，重启 PHP。 |
| HTTPS 证书申请失败 | 域名未解析或端口未放行 | 检查 A 记录、DNS 生效情况和 80/443 端口。 |
